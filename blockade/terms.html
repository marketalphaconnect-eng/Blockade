Version 1.0 • Last updated: 27th August 2026

By installing the Blockade browser extension, utilizing our command dashboard, or connecting via Private DNS synchronization, you agree to these operational terms.

1. Service Tiers & Feature Allocations

Blockade is provided under two primary functional tiers:

  • Free Pass: Provides up to 2 domain block rules, up to 2 recurring focus schedules, and a fixed 2-minute temporary access bypass window operating locally within your Chrome browser.
  • Pro Pass (14-Day Free Trial, 6-Month Pass & 12-Month Annual Pass): Unlocks up to 50 domain/subdomain rules with custom categories, up to 10 automated focus schedules, extended temporary access windows (15, 30, and 60 minutes), and cross-platform Private DNS protection across Android, iOS, Windows, macOS, and ChromeOS.

Infrastructure Retention upon Plan Expiry: Dedicated Private DNS profiles and server-synchronized schedule allocations are reserved exclusively for active Pro Pass accounts. Upon plan expiration or non-renewal, external DNS filtering endpoints are deactivated immediately. If an account remains inactive for more than 7 days following expiration, the remote Private DNS container and server-synced rule tables are automatically purged to release infrastructure resources. Local browser rules remain under your manual control.

Attempting to reverse engineer, tamper with client-side verification parameters, or redistribute modified extension binaries is strictly prohibited.

2. DNS Protection & Network Limitations

The Multi-Device Protection Hub operates by intercepting domain resolution lookups via secure Private DNS. While this blocks target endpoints across modern mobile and desktop operating systems, certain applications that utilize hardcoded IP addresses or proprietary DNS-over-HTTPS resolvers may bypass external DNS filtering. Blockade cannot block connections that circumvent standard system DNS resolution.
